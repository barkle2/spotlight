# Spotlight

마우스 강조와 포인터 확대를 제공하는 Windows 프로그램입니다.

## 현재 상태

- 버전: 1.0.0
- 배포 주체: 고용노동부 김동현
- 저작권: Copyright © 2026 고용노동부 김동현
- 기능 개발·현재 EXE·배포 ZIP 실행 검증 완료. 기관 보안 검토와 최종 버전 완료 판정은 별도 관리합니다.
- 다른 기관의 사용·공유를 허용합니다. 구성별 라이선스 조건은 라이선스 안내를 따릅니다.

| review-package-report.json | ZIP 크기·파일 개수·SHA-256·검증 결과 |

## 실행 환경과 사용

- 대상: Windows 11, 64비트.
- EXE 실행에는 Python 설치가 필요 없습니다.
- Microsoft Visual C++ 런타임 DLL은 동봉하지 않습니다. 대상 PC에 호환되는 x64 v14 런타임이 설치되어 있어야 합니다. 설치가 필요하면 기관에서 허용한 Microsoft 공식 설치본을 사용합니다.
- 일반사용자용 ZIP을 압축 해제하고 Spotlight.exe를 실행합니다. `_internal/` 폴더를 함께 유지합니다.
- 알림 영역의 Spotlight 아이콘을 오른쪽 클릭하면 **정보 / 설정 / 종료**가 표시됩니다. 더블 클릭으로 설정을 엽니다.
- 같은 Windows 세션에서 중복 실행을 차단합니다. 종료는 트레이 메뉴를 사용합니다.

## 기능과 설정

| 탭 | 기본값과 기능 |
| --- | --- |
| 강조원 | 켜짐, 지름60, 노랑 #FFFF00, 불투명도30%, 채움. 크기·색상·불투명도·채움/테두리·두께 설정 |
| 클릭 | 켜짐, 왼쪽 #00AAFF·오른쪽 #FF6600, 180ms, 테두리·두께3 |
| 휠 | 켜짐, #00CC66, 250ms, 두께3. 강조원 지름 안에서 확대/축소 |
| 포인터 | 확대 꺼짐, 1단계. 1~15단계(32~256px) 슬라이더로 선택 |

- 네 기능은 독립적으로 활성화합니다. 색상은 코드 입력 또는 색상 선택으로 지정합니다.
- 유효한 변경은 즉시 미리 보입니다. 적용은 저장하고 창을 유지하며 확인은 저장 후 창을 닫습니다.
- 취소·X·Esc는 마지막 적용값으로 돌아갑니다. 전체 초기화는 기본값을 미리 보여주며 적용·확인해야 저장합니다.
- 클릭·휠 효과는 생성 위치에 고정됩니다. 동시에 합계 최대3개를 유지합니다.
- 설정: `%LOCALAPPDATA%/Spotlight/settings.ini`. 재실행 시 적용값을 유지합니다.
- 포인터 확대 해제·정상 종료 시 현재 Windows 커서 설정으로 복원합니다. 강제 종료 후에는 재실행으로 복구를 시도합니다.
- 복구 표식 오류가 발생하면 cursor-recovery.json을 임의 삭제하지 말고 원인을 확인합니다.
- 콘솔 없는 EXE의 출력·오류는 사용자 설정 폴더의 `logs/`에 기록합니다.

## 소스 실행과 빌드

기준 개발 환경은 Python 3.13.13 x64, PySide6 6.11.2, PyInstaller 6.22.3입니다. 프로젝트 루트에서 실행합니다.

```powershell
python -m pip install -r requirements.txt
python run_spotlight.py
```

```powershell
python -m pip install -r packaging/requirements-build.txt
powershell -NoProfile -ExecutionPolicy Bypass -File packaging/build.ps1
```

- 소스는 src/spotlight/, 빌드 코드는 packaging/, 검증 코드는 validation/에 있습니다.
- 새 빌드마다 고유한 build/dist 경로와 보고서를 생성합니다. 새 EXE 검증 후 패키징 도구의 기준 ID·해시를 갱신합니다.
- 현재 패키징 도구 참조 때문에 기준 EXE 폴더와 build 보고서를 보존합니다.
