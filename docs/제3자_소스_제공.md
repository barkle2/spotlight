# 제3자 라이브러리 소스 제공·교체 안내

- 기준: Spotlight 1.0.0, 빌드20261009-230724-55c27214.
- 상태: 검토용 안내. 제공 소스와 실제 wheel 빌드의 수정/설정 대응 및 Microsoft 런타임 조건 확인은 아직 완료 전입니다.

## 제공할 자료

실행 묶음과 별도로 Spotlight-third-party-sources 폴더/ZIP을 같은 전달 위치에 제공합니다. 실제 배포 시 수신자가 인터넷 없이 이 자료에도 접근할 수 있어야 합니다. 소스 자료가 빠진 실행 묶음만으로 제공 절차 완료라고 표시하지 않습니다.

| 자료 | 내용 |
| --- | --- |
| qtbase-everywhere-src-6.11.2.zip | Core/Gui/Widgets/Network/OpenGL 등 QtBase |
| qtsvg-everywhere-src-6.11.2.zip | SVG 라이브러리/플러그인 |
| qtimageformats-everywhere-src-6.11.2.zip | 추가 이미지 플러그인 |
| qttranslations-everywhere-src-6.11.2.zip | 번역 자료 |
| pyside-setup-everywhere-src-6.11.2.zip | PySide/Shiboken 소스 |
| mesa-11.2.2.tar.xz | 소프트웨어 OpenGL 관련 Mesa 소스 |
| source-inventory.json / mesa-source-inventory.json | 보관 파일 크기/해시/고지 목록 |

위 목록은 확보한 upstream 원본입니다. 실제 배포 binary의 모든 빌드 수정·패치·설정까지 확인한 대응 소스 완성 선언은 아닙니다. 필요한 추가 자료는 제공본과 대조 후 보완합니다. Spotlight 자체 소스와 소스코드 설명서는 이 목록과 구분합니다.

## 라이브러리 사용과 교체

Spotlight는 Qt/PySide/Shiboken 동적 라이브러리를 사용합니다. 제3자 원문의 라이선스 권리와 조건을 적용하며, 이 문서는 해당 권리를 제한하지 않습니다. 특히 해당 라이브러리 수정·교체와 그 변경을 디버깅하기 위한 역공학을 Spotlight의 사용·공유 안내로 금지하지 않습니다.

교체 절차는 개발/시험 복사본에서 수행합니다.

1. 실행 중인 Spotlight를 트레이에서 정상 종료합니다.
2. 배포 폴더 전체를 별도 위치에 복사합니다.
3. 같은 아키텍처와 호환되는 API/ABI로 라이브러리를 준비합니다. Qt/PySide/Shiboken 및 플러그인 의존성을 함께 확인합니다.
4. 해당 복사본의 _internal 아래 대응 파일을 교체합니다. DLL 이름만 같다고 호환되는 것은 아닙니다.
5. 변경 복사본을 실행하여 입력·설정·정보·효과·종료/커서 복원을 확인합니다.

업스트림 소스에는 빌드 안내와 설정 도구가 포함됩니다. 실제 기존 binary의 완전 동일 재생성은 별도 빌드 조건 확인이 필요합니다. 라이브러리가 바뀌면 기존 배포 보고서의 검증을 변경본에 그대로 적용하지 않습니다. EXE 해시만으로 변경된 DLL을 식별할 수 없으므로 전체 파일 목록과 해시도 새로 기록합니다.

## 전달 및 유지

- 실행 묶음의 라이선스 안내와 원문을 함께 유지합니다.
- 외부 소스 ZIP은 같은 전달 위치에서 함께 제공하도록 구성합니다.
- 기관 보안 검토와 오픈소스 고지/소스 제공 준비는 서로 다른 상태로 기록합니다.
- 현재 작업은 검토용 묶음을 준비하는 단계이며 기관 배포 승인·라이선스 확인 완료를 대신하지 않습니다.
