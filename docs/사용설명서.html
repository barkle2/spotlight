Spotlight 1.0.0 · 고용노동부 김동현

설정 화면을 따라 강조원·클릭·휠 효과와 포인터 확대를 사용해 보세요.

인터넷 연결 없이 읽을 수 있습니다. 화면 이미지는 클릭하여 확대합니다.

1. 실행과 트레이 메뉴

  1. 배포받은 Spotlight 폴더 전체를 원하는 위치에 둡니다.
  2. Spotlight.exe를 실행합니다.
  3. 작업표시줄 알림 영역에서 노란 원과 흰색 커서 아이콘을 찾습니다. 숨겨져 있으면 숨겨진 아이콘 표시 버튼을 누릅니다.
  4. 아이콘을 우클릭하여 정보·설정·종료를 선택합니다. 더블 클릭하면 설정 창이 열립니다.
EXE와 _internal 폴더를 함께 유지해 주세요. 실행 PC에 Python을 설치할 필요는 없습니다.

2. 강조원 설정

트레이에서 설정 → 강조원을 선택합니다.

  • 활성화: 커서를 따라가는 강조원을 켜거나 끕니다.
  • 지름: 원의 크기를 조절합니다.
  • 색상: 색상 선택 버튼으로 팔레트를 열거나 #RRGGBB 형식으로 입력합니다.
  • 불투명도: 높을수록 진하게 표시됩니다. 0%에서는 보이지 않습니다.
  • 표시 방식: 채움 또는 테두리를 선택합니다.
  • 선 두께: 테두리 방식에서 조절합니다.

확인 결과: 변경한 강조원이 커서를 따라 표시됩니다.

3. 클릭 효과 설정

클릭 탭을 선택합니다.

  • 활성화 체크로 클릭 효과만 켜거나 끕니다.
  • 왼쪽·오른쪽 클릭 색상을 각각 선택합니다.
  • 지속 시간은 효과가 표시되는 시간이며 단위는 ms입니다. 1000ms는 1초입니다.
  • 채움 또는 테두리를 선택하고, 테두리에서는 선 두께를 조절합니다.

확인 결과: 클릭한 위치에 효과가 나타났다가 사라집니다. 마우스를 움직여도 효과는 생성 위치에 남습니다.

4. 휠 효과 설정

휠 탭을 선택합니다.

  • 활성화 체크로 휠 효과만 켜거나 끕니다. 원래 스크롤은 유지됩니다.
  • 색상·지속 시간·선 두께를 조절합니다.
  • 위로 돌리면 테두리가 커지고, 아래로 돌리면 작아집니다.

확인 결과: 생성 당시 강조원 범위 안에서 효과가 확대·축소됩니다. 효과 위치는 생성된 위치에 고정됩니다.

클릭과 휠 효과는 합계 최대 3개까지 표시됩니다.

5. 포인터 확대

포인터 탭을 선택합니다.

  1. 포인터 확대 사용을 체크합니다.
  2. 슬라이더로 1~15단계를 선택합니다.
  3. 슬라이더를 놓고 실제 포인터 크기를 확인합니다.

드래그 중에는 단계와 크기 문구가 바뀌고, 놓으면 시스템 커서에 반영됩니다.

확인 결과: 화살표뿐 아니라 텍스트 입력·링크 등에서 사용하는 커서도 확대됩니다. 확대를 끄면 현재 Windows 설정으로 복원됩니다.

아래 캡처는 확대 사용이 켜진 1단계 상태입니다. 최초 기본값은 확대 꺼짐입니다. 1단계는 32×32px, 5단계는 96×96px, 15단계는 256×256px입니다.

6. 저장·취소·전체 초기화

입력값을 변경하면 저장 전에 화면에 미리 반영됩니다.

버튼동작
적용설정을 저장하고 창을 유지합니다.
확인설정을 저장하고 창을 닫습니다.
취소·X·Esc마지막 적용값으로 돌아갑니다. 적용하지 않은 변경은 저장하지 않습니다.
전체 초기화모든 설정을 기본값으로 미리 표시합니다. 적용 또는 확인을 눌러야 저장됩니다.

적용 → 추가 변경 → 취소 순서에서는 앞서 적용한 값이 유지됩니다. 초기화 후에도 저장 전에는 취소로 되돌릴 수 있습니다.

기본값: 강조원 지름 60·노란색·불투명도 30%·채움, 클릭 효과 테두리, 휠 효과 켜짐, 포인터 확대 꺼짐입니다.

7. 정보 확인과 종료

트레이의 정보를 선택하면 별도 정보 창이 열립니다. 제품명·버전·배포 주체·저작권과 실행 파일의 SHA-256을 확인할 수 있습니다.

해시 대상 경로는 설치 위치에 따라 달라집니다. 파일이 변경되거나 재빌드되면 해시도 달라질 수 있습니다. 소스 실행에서는 배포 EXE 대신 run_spotlight.py의 해시를 표시합니다.

닫기·X·Esc는 정보 창만 닫습니다. 프로그램을 끝내려면 트레이의 종료를 선택합니다.

확인 결과: 강조원·효과·트레이 아이콘과 열린 창이 닫히고, 확대했던 시스템 커서는 현재 Windows 설정으로 복원됩니다.

8. 발표·녹화와 사용 시 참고

  • Office Home 2016: 슬라이드쇼에서 강조원이 회색으로 보이면 파일 → 옵션 → 고급 → 표시의 ‘하드웨어 그래픽 가속 사용 안 함’을 체크한 조건에서 정상 색상을 확인했습니다.
  • Windows 캡처 도구: 화면 영역 녹화에서 강조원·클릭·휠 효과가 포함되는 것을 확인했습니다. PC에 녹화 기능이 있는지 확인해 주세요.
  • Xbox Game Bar: 화면에서는 효과가 보여도 녹화 영상에는 누락될 수 있습니다.
  • oCam: 최소화 후 Chrome 녹화는 정상입니다. oCam 자체 창 위에서는 클릭·휠 효과가 표시되지 않는 제한이 있습니다.

Windows 11, 두 모니터의 100·150·175%와 혼합 배율에서 확인했습니다. Windows 10·200%·원격 환경·관리자 앱 등은 별도 미검증입니다.

설정과 로그는 %LOCALAPPDATA%\Spotlight에 저장됩니다. 강제 종료 후에는 프로그램을 다시 실행하여 복구하도록 해 주세요. 복구 오류가 있으면 표식을 임의 삭제하지 말고 로그를 확인해 주세요.
