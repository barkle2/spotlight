- 상태: 원문 자료·고지·upstream 소스 6개 확보 및 검토용 ZIP 동봉 검사 완료. 실제 제공 라이브러리와 완전한 대응 소스/빌드 조건의 대조 및 Microsoft 런타임 재배포 조건은 확인 중입니다.

## 1. Spotlight 자체

저작권 표기는 배포 주체 식별용입니다. 사용자 결정에 따라 다른 기관에서도 Spotlight를 사용하고 공유할 수 있습니다. 수정·판매 등 추가 권한은 이번 결정으로 확정하지 않았습니다. 제3자 구성 요소의 라이선스상 권리는 이 안내로 제한하지 않습니다. 제3자 라이선스 안내가 Spotlight 전체에 같은 라이선스를 부여하는 것은 아닙니다. 소스코드 설명서는 구조 설명 문서이며 전체 프로그램 소스가 아닙니다.

Qt Virtual Keyboard/PDF/QML/Quick 지정 파일 9개는 이번 후보에서 제외되었고 산출물 검사로 확인했습니다. 모든 Qt 제3자 의존성이 제거되었다는 뜻은 아닙니다.

## 3. Qt/PySide 오픈소스 배포 준비

공식 LGPL 안내는 라이선스 고지/원문 제공, 사용 라이브러리의 대응 소스 제공 또는 해당 조건을 만족하는 제공 방식, 라이브러리 교체·재연결 등 수신자의 권리 보장을 설명합니다. 링크 목록만 붙이거나 DLL로 나누었다는 사실만으로 이 항목들을 모두 충족했다고 표시하지 않습니다.

내부망 수신자가 실제로 사용할 수 있도록 다음 자료를 준비합니다.

- 사용 버전에 맞는 LGPL/GPL 원문과 저작권·제3자 고지.
- 사용 라이브러리의 대응 소스 확보 및 전달/제공 방식.
- 변경 라이브러리 사용·교체에 필요한 설명과 해당 권리를 제한하지 않는 배포 조건.
- 해당 버전 Qt 내부 제3자 고지와 배포 파일 목록의 대조.

오픈소스 라이선스 선택과 대응 자료를 확인하기 전에는 초안의 구성 표를 최종 준수 완료 선언으로 사용하지 않습니다.

## 12. Windows용 Python에 포함된 Microsoft 코드 조건

Python 제공분의 Windows 추가 조건은 licenses/Python-LICENSE.txt의 Additional Conditions for this Windows binary build에 있습니다. 원문과 해당 고지를 유지하고 재배포자/외부 최종사용자도 해당 코드 보호 조건을 준수하도록 안내합니다. Microsoft 고지를 변경하거나 Microsoft가 제작·후원한 프로그램으로 오인시키지 않아야 하며, 해당 코드의 플랫폼 및 사용 제한은 동봉 원문을 따릅니다. 이 조건은 Python 전체나 Spotlight 자체에 동일한 제한을 부여하는 것으로 해석하지 않습니다. PySide/Shiboken에서 제공된 별도 Microsoft 런타임의 적용 조건은 별도 확인 항목입니다.

## 13. 현재 후보의 Microsoft runtime 비동봉

- 20261010-015418-69047fee EXE 배포 폴더에는 MSVCP/VCRUNTIME 등 Visual C++ runtime DLL이 없습니다. 산출물17검사와 실제 실행 검증으로 확인했습니다.
- 이 문서의 runtime 동봉 조건 확인 기록은 이전 후보 조사 이력입니다. 현재 방식은 대상 PC의 적법한 설치본을 사용하므로 해당 DLL을 Spotlight ZIP으로 재배포하지 않습니다.
- 대상 PC 런타임 설치·사용 조건은 Microsoft 원문을 따릅니다. Python 등 나머지 동봉 구성의 라이선스/고지는 유지합니다.
