# Spotlight 1.0 사용설명서

- 버전:1.0.0, 배포 주체:고용노동부 김동현.
- 상태:배포 후보 검증 중. 기관 보안 검토는 추후 예정이며 현재 미서명입니다.

## 실행과 종료

1. 배포 폴더 전체를 원하는 위치에 복사합니다.
2. Spotlight.exe를 실행합니다. Python 설치는 필요하지 않습니다.
3. 알림 영역의 노란 원·흰색 커서 아이콘을 우클릭하여 정보 / 설정 / 종료를 선택합니다. 더블 클릭으로도 설정을 엽니다.

- Spotlight.exe와_internal 폴더를 함께 유지해야 합니다. EXE만 복사하면 실행되지 않을 수 있습니다.
- 같은 Windows 세션에서 중복 실행은 차단됩니다.
- 정상 종료는 트레이의 종료를 사용합니다. 포인터 확대는 현재 Windows 커서 설정으로 복원됩니다.

## 설정

| 탭 | 설정 |
| --- | --- |
| 강조원 | 활성화, 지름, 색상, 불투명도, 채움/테두리, 선 두께 |
| 클릭 | 활성화, 좌우 색상, 지속 시간, 채움/테두리, 선 두께 |
| 휠 | 활성화, 색상, 지속 시간, 선 두께 |
| 포인터 | 확대 활성화,1~15단계 크기 슬라이더 |

- 색상은 견본·#RRGGBB 입력·팔레트로 선택합니다. 팔레트 취소는 현재 값을 유지합니다.
- 포인터 슬라이더는 드래그 중 단계/크기를 표시하고 놓으면 실제 커서에 반영합니다.1/5/15단계는32/96/256px입니다.
- 변경은 프리뷰로 표시됩니다. 적용은 저장하고 창을 유지하며 확인은 저장 후 창을 닫습니다.
- 취소·X·Esc는 마지막 적용값으로 복구합니다.
- 전체 초기화는 팝업 없이 모든 기본값을 프리뷰합니다. 적용·확인으로 저장하며 취소로 되돌릴 수 있습니다.
- 기본 강조원 지름60·노란색·불투명도30%·채움, 클릭 효과는테두리, 휠 켜짐, 포인터 확대 꺼짐/1단계입니다.
- 클릭·휠 효과는 생성된 위치에 고정되고 합계 최대3개입니다. 마우스가 이동해도 생성 위치에 남았다가 만료됩니다.

## 정보

- 트레이 메뉴의 정보에서 제품명·설명·버전·배포 주체·파일명·저작권·실행파일 SHA-256을 별도 창으로 확인합니다.
- 다시 선택하면 기존 정보 창을 앞으로 가져옵니다. 닫기·X·Esc로 닫아도 프로그램은 계속 실행됩니다.
- 소스 실행에서는 run_spotlight.py의 해시를 표시하며 배포 EXE 해시와 구분합니다.
- 정보 창 분리와 정보·설정 창 Spotlight 아이콘은 새 EXE에서도 사용자 확인을 완료했습니다.

## 설정·로그·복구

- 설정:%LOCALAPPDATA%\Spotlight\settings.ini
- 복구 표식:%LOCALAPPDATA%\Spotlight\cursor-recovery.json
- 콘솔 없는 실행의 로그:%LOCALAPPDATA%\Spotlight\logs\spotlight-*.log
- 설정 폴더는LOCALAPPDATA가 없으면 사용자 홈의AppData/Local/Spotlight를 사용합니다.
- 강제 종료 후에는 일반 실행을 다시 시작하여 이전 복구 표식을 처리합니다. 저장된 확대가 켜져 있으면 복구 후 다시 확대됩니다.
- 복구 오류가 있으면 표식을 임의 삭제하지 말고 로그를 확인합니다.

## 슬라이드쇼·녹화

- Office Home2016:슬라이드쇼 강조 원이 회색으로 보이면 파일→옵션→고급→표시의 일반 **하드웨어 그래픽 가속 사용 안 함**을 체크한 조건에서 정상 색상을 확인했습니다.
- Windows 캡처 도구의 화면 영역 녹화:강조원·클릭·휠 효과 포함 확인. 실제 내부망 PC에도 녹화 기능이 있는지는 별도 확인합니다.
- oCam:최소화 후Chrome 녹화 정상. oCam 자체 창 위에서는 클릭·휠 효과가 표시되지 않는 제한이 있습니다.
- Xbox Game Bar:실제 화면 효과는 보이나 저장 영상에서 효과가 누락되었습니다. 효과 포함 녹화에는 캡처 도구를 사용합니다.
